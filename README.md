# GitHub Explained 🚀

## 📌 Introduction
GitHub is a web-based platform used to store, manage, and share code.
It is built on Git, which is a version control system that tracks changes
in files and helps developers collaborate efficiently.

---

## 🔧 What is Git?
Git is a version control system that:
- Tracks changes in source code
- Allows multiple people to work on the same project
- Helps restore previous versions of code

👉 GitHub is an online platform that uses Git.

---

## 📂 Key Features of GitHub
- **Repositories** – Store project files and code
- **Branches** – Work on new features separately
- **Commits** – Save changes with messages
- **Pull Requests** – Review and merge code
- **Issues** – Track bugs and tasks
- **Actions** – Automate testing and deployment

---

## 🔄 How GitHub Works
1. Create a repository
2. Write or modify code
3. Commit changes
4. Push code to GitHub
5. Collaborate with team members
6. Merge final code
